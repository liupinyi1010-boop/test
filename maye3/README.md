# 估價嗎耶通

最方便的語音估價單：打開網頁，按麥克風說施工內容，也可以順便說客戶姓名、電話和地址。說完就在下方出現整份報價單預覽（跟列印／PDF 同一種格式），再按「下載報價單」選 PDF 或 Excel。如需修改，請在 Excel 裡自行調整。

GitHub Pages 請用這個網址開啟，以免快取到舊檔（v3 在 `maye3/` 資料夾）：

`https://liupinyi1010-boop.github.io/test/maye3/?v=4.3`

若要從 LINE 開啟並使用麥克風／語音辨識，建議加上強制外部瀏覽器參數：

`https://liupinyi1010-boop.github.io/test/maye3/?v=4.3&openExternalBrowser=1`

## 檔案
- `index.html`：估價嗎耶通網頁（以手機為主，大字、大按鈕）
- `styles.css`、`app.js`、`ai-adapter.js`：畫面與邏輯
- `price_db.json`：水電／木工／油漆市場行情（不虛構單價）
- `taigi_terms.json`：台語／工地用語與同音字變體
- `user_corrections.json`：師傅確認的語音聽寫優先修正（可再追加；產生估價單前先套用，不在畫面列出原文）
- `exceljs.min.js`：匯出 Excel 用

語音使用瀏覽器內建辨識（需 https）。若瀏覽器不支援，請改打字、用鍵盤聽寫，或改用 Safari／Chrome。雲端估價走既有轉接服務。沒有行情的項目標「待填」。離開再回來資料會保留，除非重新錄音或按清除。產生後直接顯示整份報價單預覽（不是一列一個框，也不再列出辨識原文）；不能在畫面上改欄位；下載的 Excel 可改數量與單價，複價與合計會自動重算。錄音時麥克風下方會出現簡短即時文字與計時。畫面依 50 歲以上使用者調整：字體加大、綠色大按鈕寫「按這裡開始講／講完了」、有口語說明與示例、合計數字放大、下載視窗兩個大選項，並在 LINE 內建瀏覽器提示改用外部開啟。v3.7 將操作介面改成溫暖米灰與炭黑、焦糖點綴的圓角風格；報價單內容、單價與操作流程與 v3.6 相同（頁面上方沒有 1～4 步驟區塊）。v3.8 在頁首標題後方加上淡化、霧化的施工場景作為背景。v3.9 改為接近 iOS 系統設計的介面，並加上情境引導。v4.0 新增明亮／深色模式與字體大中小，麥克風改為霧面玻璃圓圈，區塊帶微漸層，頁首加上六角房屋／G 標誌與英文名稱 Good Job My tone。v4.1 把麥克風後方的色塊限制在圓圈內並調淡，避免擋住下方文字；產生估價單後仍在同一頁顯示合計與報價單預覽，點預覽才開可捲動的完整彈窗，頁面上也保留「下載報價單」。頁首標誌改為使用者選定的六角房屋與中間等角麥克風圖樣，僅裁切圓角與縮放，沒有重繪形狀。報價單內容、單價與操作流程不變，也沒有加回頂部 1～4 步驟區塊。 v4.2 移除「下載報價單」區塊裡的「查看報價單」按鈕，要看完整報價單請直接點預覽。v4.3 拿掉麥克風上方的三個步驟圖示與頁首「語音估價」四字；麥克風周圍改為均勻的圓形淡光暈，不再出現方形色塊；頁首標誌去掉圓角外框，高度與「估價嗎耶通」標題相同，英文 Good Job My tone 的寬度與中文標題對齊。
