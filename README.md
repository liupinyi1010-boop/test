# 師傅估價通

最方便快速的估價單，讓你輕鬆把握案場主導權。

## 檔案
- `index.html`：估價通網頁（電腦／手機自動切換版面）
- `price_db.json`：工項單價資料

## 使用方式
直接用瀏覽器打開 `index.html`。若是 GitHub Pages，請用 `?v=56` 開啟以免快取到舊版（例如 `https://liupinyi1010-boop.github.io/test/?v=56`）。圖面分析、報價小精靈、估價小幫手需在設定中填入「AI 金鑰」才能使用；未填時會顯示提示，其餘估價功能正常。麥克風需在 https 網址下才能使用。

## 主要功能
- 依序六步流程：選工種 → 上傳平面圖（自動判斷平面圖／水電圖／3D 透視，最多 10 張）→ 選範本 → 案場條件 → 估價單預覽（手動加入項目）→ 估價小幫手（進階方案）
- 依門寬比例推算櫃體尺數，3D 判斷高櫃／矮櫃，套用到估價單
- 方案：基本 NT$500/月、進階 NT$700/月（含稅）
- 明亮／深色模式、字體大小調整
